## PROMPT 12 — Frontend: full routing and core pages

Build the complete React frontend.

**Create /client/src/context/AuthContext.tsx:**
- Stores: clientUser, JWT, isLoading
- login(email, password) → calls API, stores JWT in localStorage, handles requiresReconsent
- logout() → clears localStorage, redirects to /login
- updateClientUser(updates) → updates local state

**Create /client/src/hooks/useProductAccess.ts:**
- Reads clientUser.products (fetched from GET /api/auth/me which includes products)
- Returns: { hasExcellenceLab, hasEvidenceVault, hasEliteBlueprint, isLoading }

**Create /client/src/lib/api.ts:**
- Axios instance with baseURL='/api'
- Request interceptor: add Authorization: Bearer {JWT} from localStorage
- Response interceptor: catch 403 { requiresReconsent: true } → trigger DisclaimerContext

**Build these pages fully (not placeholders):**

1. ClientRegister — form with: first_name, last_name, email, password, two disclaimer checkboxes (required). Calls POST /api/auth/register.

2. ClientLogin — email + password form. Handles requiresReconsent by showing ReconsentModal.

3. ReadinessIntake — multi-step form collecting all intake fields. On completion calls intake complete endpoint which triggers Drive folder creation. Shows progress bar.

4. Dashboard — welcome panel, AI profile summary button, product status cards (Excellence Lab, Evidence Vault, Elite Blueprint), action items section, My Documents section (published docs only, read-only).

5. EvidenceVaultDashboard — criteria-mapped view:
   - One card per criterion for client's visa path
   - Shows evidence count per criterion
   - Drive folder link per criterion
   - "Add Evidence" button on each card (pre-selects that criterion)
   - AddEvidenceDialog: criterion dropdown (pre-filtered to visa path), description of legal standard shown, "will save to: {folderName}" preview
   - AIOutputBanner above gap analysis section

6. ExcellenceLabLesson — fetches lesson content from GET /api/lessons/:id. Shows LessonDisclaimer at top. Renders personalized content sections. Complete button. Evidence prompt with link to add evidence.

7. EliteBlueprintApply — full application form. On submit shows confirmation page.
