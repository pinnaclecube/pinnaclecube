> ### STEP 3 — Client-Side Page Visit Tracking
>
> Create a lightweight React hook `usePageTracking(pageName: string)` in `artifacts/pinnacle/src/hooks/usePageTracking.ts`:
>
> ```typescript
> export function usePageTracking(pageName: string, metadata?: Record<string, unknown>) {
>   useEffect(() => {
>     const startTime = Date.now();
>     // Fire page_visit event on mount
>     fetch('/api/activity/page-visit', {
>       method: 'POST',
>       headers: {
>         'Content-Type': 'application/json',
>         'Authorization': `Bearer ${localStorage.getItem('pinnacle_token')}`
>       },
>       body: JSON.stringify({ pageName, metadata })
>     }).catch(() => {}); // silent fail
>
>     // Fire page_exit event with duration on unmount
>     return () => {
>       const duration = Math.round((Date.now() - startTime) / 1000);
>       navigator.sendBeacon('/api/activity/page-exit', JSON.stringify({
>         pageName,
>         durationSeconds: duration,
>         metadata
>       }));
>     };
>   }, [pageName]);
> }
> ```
>
> Add `POST /api/activity/page-visit` and `POST /api/activity/page-exit` client-auth endpoints that call `logActivity` with:
> ```
> eventType: 'page_visited' / 'page_exited'
> actor: 'client'
> category: 'navigation'
> metadata: { pageName, durationSeconds (on exit) }
> ```
>
> Add `usePageTracking()` to these client portal pages:
> - `my-files.tsx` → pageName: 'Case Files'
> - `tasks.tsx` → pageName: 'My Tasks'
> - `evidence/index.tsx` → pageName: 'Evidence Engine'
> - `dashboard.tsx` → pageName: 'Dashboard'
> - `where-you-stand.tsx` → pageName: 'Where You Stand'
> - `criteria/index.tsx` → pageName: 'Criteria'

> ### STEP 4 — Rebuild the Activity Log API
>
> Replace the existing `GET /admin/profiles/:id/activity-log` handler with:
>
> ```typescript
> GET /admin/profiles/:id/activity-log
>   Query params:
>     limit: number (default 50, max 200)
>     offset: number (default 0) — for pagination
>     category: string (optional — filter by category)
>     actor: string (optional — 'client' | 'staff' | 'system')
>     from: ISO date string (optional)
>     to: ISO date string (optional)
>     search: string (optional — searches description and metadata)
>
>   Returns:
>   {
>     events: ActivityLogEntry[],
>     total: number,        // total count matching filters (for pagination)
>     hasMore: boolean,     // offset + limit < total
>     summary: {
>       lastLogin: timestamp | null,
>       lastActivity: timestamp | null,
>       totalEvents: number,
>       eventsByCategory: Record<string, number>,
>       filesUploaded: number,
>       tasksCompleted: number,
>       exhibitsViewed: number,
>       pagesVisited: number,
>       avgSessionDuration: number | null,
>     }
>   }
> ```
>
> Also merge the `activity` table events into the response — join both tables by `profileId` and `createdAt`, union them, sort by `createdAt DESC`. Map `activity` table events to the new schema: `actor: 'client'`, `category: 'system'`, `description: activity.description`.
