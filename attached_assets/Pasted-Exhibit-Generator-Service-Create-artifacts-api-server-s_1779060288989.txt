•	Anthropic from @anthropic-ai/sdk

•	All relevant DB tables from @workspace/db
Export these six async functions. Every function must:
•	Create a document_generation_jobs record at the start with appropriate docSubtype
•	Update job status to 'processing' when work begins
•	Set status: 'completed' and completedAt: new Date() on success
•	Set status: 'failed' and errorMessage on failure
•	Be called fire-and-forget from route handlers — never block the HTTP response

Function 1: generateCriteriaExhibits(caseSetupId: number, criteriaCode: string, triggeredByStaffId: string): Promise<void>
1.	Load criteria row from petition_criteria_exhibits
2.	Load client context via buildClientContext(profileId)
3.	Load assessment from criteria_assessments for this caseSetupId + criteriaCode
4.	Load documents via fetchCaseDocuments — filter to this criteria + Resume + Demographics
5.	Load config from EXHIBIT_GENERATION_CONFIG for visa category + criteria name
6.	Determine exhibit letter from criteriaCode position in the ordered criteria list
7.	Get Exhibits Drive folder ID via getCaseDriveFolderId(caseSetupId, 'exhibits')
Make three sequential Claude API calls:
Call 1 — Main Document (max_tokens: 4000):
system: baseSystemPrompt + mainDocument.systemPrompt
user: [client name, visa, criteria name, CFR, requirement, key elements,
       assessment strengths/weaknesses/adjudicator concerns,
       all document text content]
       "Generate the complete Main Criterion Document. Output legal prose only —
       no markdown fences, no code blocks, no commentary outside the document."
Build PDF using legalPdfTemplate: createDocument → addSectionHeading per section → addBodyText per paragraph → finalizePdf Upload via uploadPdfToDrive(pdfBuffer, 'Main_[criteriaCode]_[clientName].pdf', exhibitsDriveFolderId) Save to exhibit_documents table
Call 2 — Index Exhibit (max_tokens: 3000):
system: baseSystemPrompt + indexExhibit.systemPrompt
user: [same context + list of all files in criteria folder with names and types
       + tableType from config + instruction to reference sub-exhibits by number]
Build PDF, upload to Drive, save to exhibit_documents with exhibitLabel: '[letter]1'
Calls 3+ — Sub-Exhibits (max_tokens: 3000 each): One call per document in the criteria folder:
system: baseSystemPrompt + subExhibit.systemPrompt
user: [single document text + criteria context + exhibit number A2/A3/etc
       + "include figure placeholders where data supports charts"]
Build PDF per sub-exhibit, upload to Drive, save to exhibit_documents await new Promise(r => setTimeout(r, 1500)) between sub-exhibit calls
Update petition_criteria_exhibits row: set status: 'draft', driveFileId, driveUrl from the main document upload
