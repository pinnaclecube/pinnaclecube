Export calculateReadinessScore(caseSetupId: number): Promise<ReadinessScore>
The score is calculated from 0–100 using these weighted components:
typescriptinterface ReadinessScore {
  total: number;                    // 0–100 final score
  band: 'getting_started' | 'in_progress' | 'building' | 'nearly_ready' | 'filing_ready';
  bandLabel: string;                // human readable
  bandColor: string;                // hex color for UI
  components: {
    driveConnected: number;         // 0 or 10
    assessmentsComplete: number;    // 0–20
    evidenceStrength: number;       // 0–15
    rfeRiskPenalty: number;         // 0 to -10 (negative)
    exhibitsGenerated: number;      // 0–20
    packageDocuments: number;       // 0–15
    publishedToClient: number;      // 0 or 10
  };
  details: {
    totalCriteria: number;
    assessedCriteria: number;
    strongCriteria: number;
    borderlineCriteria: number;
    insufficientCriteria: number;
    highRfeCriteria: number;
    proceedCriteria: number;
    generatedExhibits: number;
    publishedExhibits: number;
    coverLetterDone: boolean;
    personalDeclarationDone: boolean;
    fieldBriefDone: boolean;
    recoTemplatesDone: boolean;
    pendingTasks: number;
    completedTasks: number;
    driveConnected: boolean;
  };
  nextActions: string[];            // 3–5 specific actionable next steps
}
Scoring logic:
driveConnected:       folders exist with drive_id → 10pts, else 0

assessmentsComplete:  (assessedCriteria / totalCriteria) × 20
                      assessedCriteria = criteria_assessments rows with assessedAt not null

evidenceStrength:     ((strongCriteria × 1.0 + borderlineCriteria × 0.5) / totalCriteria) × 15

rfeRiskPenalty:       -(highRfeCriteria × 2) capped at -10

exhibitsGenerated:    (generatedExhibits / totalCriteria) × 20
                      generatedExhibits = exhibit_documents where documentType = 'main_document'

packageDocuments:     (completedPackageDocs / 4) × 15
                      completedPackageDocs = count of: coverLetterDriveFileId present,
                      personalDeclarationDriveFileId present, fieldBriefDriveFileId present,
                      recoTemplatesStatus = 'draft'

publishedToClient:    any exhibit_documents where publishedToClient = true → 10pts, else 0

total = sum of all components, clamped to 0–100, rounded to nearest integer
Band mapping:
0–20:   getting_started  "#94A3B8"  "Getting Started"
21–40:  in_progress      "#EF4444"  "In Progress"
41–60:  building         "#F59E0B"  "Building"
61–80:  nearly_ready     "#3B82F6"  "Nearly Ready"
81–100: filing_ready     "#22C55E"  "Filing Ready"
nextActions — generate 3–5 specific strings based on what's missing:

If assessedCriteria < totalCriteria → "Run assessments for [N] unassessed criteria"
If highRfeCriteria > 0 → "Address HIGH RFE risk on [N] criteria"
If generatedExhibits < proceedCriteria → "Generate exhibits for [N] approved criteria"
If !coverLetterDone → "Generate cover letter"
If !personalDeclarationDone → "Generate personal declaration"
If publishedExhibits === 0 && generatedExhibits > 0 → "Publish [N] ready exhibits to client"
If pendingTasks > 0 → "Client has [N] pending tasks awaiting completion"

Also export getAllCasesReadiness(): Promise<CaseReadinessSummary[]> which runs calculateReadinessScore for all active cases and returns an array sorted by score ascending (lowest first — most urgent at top).

javascript// Semicircle: center (100,100), radius 80, stroke-width 16
// Arc from 180° to 0° (left to right)

const cx = 100, cy = 100, r = 80;
const startAngle = Math.PI;           // 180° left

const y1 = cy + r * Math.sin(startAngle);  // always (20, 100)

const largeArc = score > 50 ? 1 : 0;
